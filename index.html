Step 1
Write your hypothesis

          
Before asking for help, say what you think is wrong and why. Use the pattern “I think the bug is … because …”. You need a new hypothesis before each hint.

        
        

        
    
      
    

      
    
        
    Step 2
    Run a small experiment
    
          
    Call the function with an input you choose, predict the result, then note what the result tells you. Add print(…) to your revision to trace values.

      Step 3
      Support ladder
      
          
      Help comes one level at a time. Each level unlocks after a new hypothesis and a new logged experiment. DebugWise will not rewrite your program.

  DebugWise AI is a learning-design prototype. Python runs in your browser with Pyodide; your code is not sent to any server.

      


  
      
    
      AI settings
      
    
      Built-in diagnosis (default). A rule-based Python analyser reads your code, the error and your hypothesis, and gives hints at three levels. It needs no account and works offline. It recognises common beginner bugs; for anything else it says so and flags low confidence.
      
    
      Claude (optional). Add your own Anthropic API key to get diagnoses and follow-up answers for any code. The key is saved only in this browser and is sent only to api.anthropic.com. Use a key with a spending limit, and do not enter it on a shared computer.
