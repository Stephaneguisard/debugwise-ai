# DebugWise AI

A Python debugging tutor for introductory programming students. Students diagnose bugs with hypotheses and experiments; help is released one level at a time. Runs entirely in the browser (Pyodide).

- `src/` source (template, app.js, engine.py, styles). `python3 build.py` writes `dist/index.html`.
- `index.html` at the repo root is the built site served by GitHub Pages.
