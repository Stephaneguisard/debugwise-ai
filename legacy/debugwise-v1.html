Step 1
Write your hypothesis

          
Before asking for help, say what you think is wrong and why. Use the pattern “I think the bug is … because …”. You need a new hypothesis before each hint.

        
        

        
    
      
    

      
    
        
    Step 2
    Run a small experiment
    
          
    Call the function with an input you choose, predict the result, then note what the result tells you. Add console.log(…) to your revision to trace values.
    
        
    
          
          
        
    
        
        
    
        
    
        
    
          
          
    
        
    
        
      
      
      

      
      
        
      Step 3
      Support ladder
      
          
      Help comes one level at a time. Each level unlocks after a new hypothesis and a new logged experiment. DebugWise will not rewrite your program.
      
        
      
      
      

      
      
        
      Step 4
      Revise and test
      
          
      Edit your copy of the code. The original stays on the left so you can compare.
      
        
        
      
        
      
      
      

      
      
        
      Step 5
      Explain the bug in your own words
      
          
      Why did the original program fail? Describe what was happening to the program’s state, not only what you changed.
      
        
        
      
        
      
      
      

      
      
        
      Step 6
      Transfer: same principle, new code
      
          
      Predict what this new code does before you run it, then say which debugging principle applies.

      Reflect
